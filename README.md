# V0ID CLIENT — The only public open-source modded 1.14.4 Eagler client

V0ID CLIENT is a community-maintained, modded EaglerCraft 1.14.4 client distribution. It is currently the only public, open-source modded 1.14.4 Eagler client and focuses on adding compatibility and visual improvements while keeping server behaviour unchanged.

## Current mods & features

- ViaTextures — Renders newer (post-1.14.4) items with their real models and textures in inventories, hotbar, hands and as dropped items. This is always on (no toggle). See VIATEXTURES.md for details and limitations.
- TuffX+ client port — Adds client support for the TuffX+ server plugin. Includes two main features you can toggle in the ClickGUI (Right Shift): **ViaBlocks** and **Below Y0**. Defaults: both ON. See TUFFX_PORT.md for protocol and engine notes.
  - ViaBlocks: accepts server-sent modern block states and overrides ViaVersion substitutes so the client displays the real blocks.
  - Below Y0: extends the client world to support negative build heights sent by the server (y0 below 0) and adds extra chunk sections and lighting support.
- ModernBlocks — Registers a collection of modern blocks (158 blocks currently) so post-1.14 blocks have client-side blockstates/models/textures. Assets are generated by `gen_modern_blocks.py` and placed into `desktopRuntime/resources/assets/minecraft`.
- Texture updates — A selection of vanilla textures was updated from newer versions (1.21.4) where needed; non-animated, same-size textures were swapped to improve visuals.

## Why it matters

Servers that use ViaVersion/ViaBackwards and server-side plugins like TuffX+ can now present modern items and blocks to a 1.14.4 Eagler client without losing the real appearance. V0ID CLIENT restores visuals while leaving server-side logic, item/tooltips and behaviour unchanged.
